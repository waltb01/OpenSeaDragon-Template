# OpenSeaDragon-Template
OpenSeaDragon Template Files (HTML, CSS, JS, With CSS-enabled Brightness and Contrast Controls

These are a set of template files to be used in conjunction with deepzoom images in JPG file format, and viewed in a browser using OpenSeaDragon javascripting.

Simply copy the folders of tiled images (01_folder, 02_folder, 03_folder ...) and paste into the /panoramics/images subfolder of your website. 

The CSS coding is designed for your website to be responsive. The CSS Brightness and Contrast Controls were added interactive convenience.
